# Требования к функциональности

Источник: [[Бизнес-процессы]]. Реализация: [[Архитектура системы]]. Проверка: [[Тестовая документация]].

## Функции
- **ФТ-1. Закупки:** заявки и заказы поставщикам.
- **ФТ-2. Склад:** приход, расход, остатки, резервирование.
- **ФТ-3. Продажи:** заказы клиентов, счета, отгрузки.
- **ФТ-4. Финансы:** платежи, взаиморасчёты, отчёты.
- **ФТ-5. Кадры:** сотрудники, табель, расчёт зарплаты.

## Интерфейс
- веб-интерфейс в браузере;
- пользователь видит только разделы, доступные его роли.

## Производительность
- открытие списка документов — не более 2 с;
- до 100 одновременных пользователей.

## Безопасность
- вход по логину и паролю;
- разграничение доступа по ролям;
- передача данных по HTTPS.
