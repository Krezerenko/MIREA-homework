# Бизнес-процессы предприятия

Процессы, которые автоматизирует система. Требования к ним: [[Требования к функциональности]].

1. **Закупка:** заявка на закупку → заказ поставщику → приёмка на склад → оплата поставщику.
2. **Продажа:** заказ клиента → резерв товара → отгрузка со склада → счёт и оплата.
3. **Кадровый учёт:** приём сотрудника → табель рабочего времени → расчёт зарплаты.
