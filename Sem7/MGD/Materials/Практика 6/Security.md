## 3. Схема обмена ключами
Опишите шаги: KEY_EXCHANGE клиента -> KEY_EXCHANGE сервера -> общий секрет -> HKDF -> ключ сессии.

## 4. Выбранные алгоритмы и обоснование
- Обмен ключами: X25519
- Вывод ключа: HKDF-SHA256
- Шифрование: AES-256-GCM (почему GCM, а не CBC):

## 5. Формат зашифрованного пакета
| Поле | Размер | Шифруется | Аутентифицируется |
|-|-|-|-|
| Header (type, seq, size) | | нет | да (AAD) |
| Nonce | 12 | нет | да |
| Payload | N | да | да |
| Tag | 16 | - | - |
